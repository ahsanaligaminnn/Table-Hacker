# Table Hacker

A simple Python-based multiplication table generator.

## Features

- Generate normal multiplication tables
- Generate even multiplication results
- Generate odd multiplication results
- Custom table start and end numbers
- Simple command-line interface
- Input validation for table value

## Categories

1. Normal
2. Even
3. Odd

## How to Run

Make sure Python is installed on your system.

Run:

```bash
python table_hacker.py
